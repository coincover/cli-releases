# Coincover CLI releases

This repository holds the customer Coincover CLI binaries.

Each published release includes the Linux, macOS, and Windows binaries and archives, plus `checksums.txt` and its Cosign signature. Download the latest from [Releases](https://github.com/coincover/cli-releases/releases).

On macOS, install with Homebrew from [coincover/key-vault-tap](https://github.com/coincover/key-vault-tap):

```bash
brew tap coincover/key-vault-tap https://github.com/coincover/key-vault-tap.git
brew install coincover
```
